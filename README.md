# Interactive Dashboard for Visualizing SAIDI Data and Energy Reliability Insights

## Overview
This project provides an interactive dashboard for visualizing and analyzing the "Annual SAIDI (System Average Interruption Duration Index) Data for Customers (2013-2025)." The dashboard enables users to explore trends, generate reports, and gain insights into the reliability of electricity distribution systems in Abu Dhabi.

## Features
1. **Interactive Data Visualization**: Explore dynamic graphs and charts that depict SAIDI trends over time.
2. **Custom Analysis**: Filter data by year, region, or other parameters to generate tailored insights.
3. **Predictive Analytics**: Forecast future SAIDI values based on historical data.
4. **Downloadable Reports**: Generate and export reports in various formats.
5. **Educational Tools**: Access tutorials, tooltips, and glossary for better understanding.
6. **Mobile-Optimized Design**: Access the dashboard seamlessly on mobile devices.

## Prerequisites
- Python 3.7+
- Pandas
- Matplotlib
- Seaborn

## Installation
1. Clone the repository:
    bash
    git clone https://github.com/your-repo-url/interactive-saidi-dashboard.git
    cd interactive-saidi-dashboard
    
2. Install required Python libraries:
    bash
    pip install pandas matplotlib seaborn
    

## Usage
1. Place your `SAIDI.csv` file in the project directory.
2. Run the Python script to generate visualizations and a summary report:
    bash
    python generate_saidi_dashboard.py
    
3. Check the output directory for:
    - Interactive visualizations.
    - A CSV report summarizing key trends and statistics.
